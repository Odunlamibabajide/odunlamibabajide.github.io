# Multi-Framework Control Crosswalk Tool

**Type:** Live, deployed web application

**Frameworks Mapped:** ISO 27001:2022, NIST CSF 2.0, SOC 2, PCI DSS v4.0, CIS Controls v8

---

## What It Does

Most GRC work — audits, gap assessments, client onboarding — requires constantly translating one framework's language into another's. This tool does that instantly: search a control domain or keyword, and see how it's expressed across five major frameworks side by side.

**[Launch the live tool →](https://control-crosswalk-tool.vercel.app/)**

**[View source code →](https://github.com/babajide/control-crosswalk-tool)**

## Features

- Search by keyword, domain name, or clause number (e.g. "encryption", "A.5.15", "Requirement 8")
- Filter results to a single framework
- Export any search result set to CSV for audit workpapers
- 15 control domains mapped, expanding over time

## Why I Built It

Coming from a GRC diploma track that emphasized multi-framework thinking, I wanted a portfolio piece that demonstrated more than framework knowledge — the ability to operationalize that knowledge into something a working analyst would actually reach for during an engagement.
